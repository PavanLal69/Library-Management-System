## LinkedIn
Most library systems stop at catalog search. But the real friction in physical collections is spatial discovery: navigating multi-floor stacks, verifying accession barcodes, and managing concurrent reservation holds.

We built the Metropolitan Library Management System (LMS) to solve this:
• 7-Tier Spatial Hierarchy (Library → Building → Floor → Section → Room → Rack → Shelf)
• Real-time Code128 physical accession barcode scanning
• ACID reservation hold engine with 48h automated expiration

Built with Next.js 16 App Router, React 19, Tailwind CSS 4, and Drizzle ORM.
